The Gym

What to do on what days. All sessions should fit into 45m. Start every lift at 3×8 for the first two weeks, build to 3×12, then add load.

Why this shape

Start with less while you adjust to eating less, then add work as recovery allows. The review evidence favors building volume up over a cut rather than backing off, with easy weeks kept in. Don't change volume just because calories dropped — change it based on recovery.

The keepers (7 movements)

Fewer moves, more load over time. Everything loads with a backpack or water jugs — no gym needed.

# Movement What it covers Load path
1 Squat Legs, bilateral Bodyweight → backpack → heavier pack
2 Bulgarian split squat Legs, unilateral (replaces split squat, lunge) Bodyweight → backpack → jugs in hands
3 Push-up (flat → decline) Chest, shoulders, triceps Incline if needed → flat → decline → backpack on back
4 Row (table → band → weighted) Back, biceps — the only pull, never drop it Higher table → band → backpack-weighted
5 Single-leg RDL Hinge, glutes, hamstrings, balance Bodyweight → jug in hand → heavier jug
6 Plank + side plank Core front + side Longer holds → harder variants
7 Farmer carry Grip, core, conditioning Heavier jugs, longer walks

Cut from the old library: pike push-ups, dips, calf raises, glute bridges, dead bugs, hollow holds, squat jumps, burnout sets — covered by the 7 or not worth the time.

Load rules

  • Reps first: start 3×8 (weeks 1–2), add reps toward 3×12. Hit 3×12 with good form, then add load (2–10%).
  • 48h before hitting the same muscles hard again. One full rest day a week.
  • If form breaks, the set doesn't count.
  • Deloads weeks 8, 12, and 16: 2 sessions, ~10 sets, no added load.
  • Lifting only works with enough protein (~1 g per lb) and 7+ hours sleep.

Sets per week

Sets/week means all the hard lifting sets added up across the week — weeks 1–4 is 2 sessions of ~15 sets = ~30, rising to ~60 in weeks 13–16. It is the workload dial: when sleep, strength, and mood hold, turn it up; when they slip, hold it. Count only sets that feel like work, not warm-ups.

Conditioning key

  • Easy cardio = 35–45 min brisk walk / bike / ruck with 20–30 lb pack — fast enough to warm you, slow enough to talk.
  • Recovery = 20-min easy walk + 10-min stretching.
  • All of it counts toward the daily step total.
